# Instructions for AI working in this repository

## Read the Record First (BFS method)

Before any work in this repository, read its record for the dates and subject at hand: its logs, the sheets and documents it mirrors, its concepts and its README. Do this at the start of every session, so no session starts blind.

- Never answer from short-term memory, an earlier chat or a summary. Those point to the record; they are not the record.
- A summary comes only from the finished record you just read.

This is Andrew Powers' BlackFox Studios method, set on 2026-11-22 to reach every AI and every system: [Read the Record First, DH_CONCEPT_028](https://github.com/Cloudenvy7/devhouse/blob/main/concepts/read_the_record_first/README.md).

For what this repository is and how it is organized, read [README.md](README.md).
